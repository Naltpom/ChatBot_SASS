## 2. Description du module

Chapote Publisher est un module de l'Espace client de Chapote. Il permet à tout client de Chapote :

- de **connecter un ou plusieurs comptes TikTok** dont il est titulaire ou qu'il est autorisé à gérer, via la connexion officielle TikTok (TikTok Login Kit) ;
- de **publier ses propres vidéos** sur ces comptes, via la Content Posting API de TikTok, soit **directement** sur le profil, soit **en brouillon** dans la boîte de réception TikTok du compte, pour finaliser la publication dans l'application TikTok ;
- de **suivre le statut** de ses publications et d'en consulter l'historique.

Avant chaque publication, le client choisit lui-même le titre, la confidentialité, les interactions autorisées et, le cas échéant, la divulgation de contenu commercial. Aucune vidéo n'est envoyée à TikTok sans un clic explicite du client sur « Publier ». Chapote n'ajoute aucun texte, hashtag, filigrane ni logo aux vidéos.

Les comptes connectés par un client ne sont visibles et utilisables que dans son propre espace (espace personnel ou équipe) : ni les autres clients ni l'éditeur ne les utilisent pour publier.

## 3. Obligations du client

En utilisant le module, le client s'engage à :

- ne connecter que des comptes TikTok dont il est titulaire ou pour lesquels il dispose d'une autorisation du titulaire ;
- ne publier que des contenus sur lesquels il détient **l'ensemble des droits nécessaires** (vidéo, musique, images, textes, droit à l'image des personnes filmées) ;
- déclarer avec exactitude tout **contenu commercial** (promotion de sa propre marque ou contenu de marque pour un tiers) ;
- respecter :
  - les [Conditions d'utilisation de TikTok](https://www.tiktok.com/legal/terms-of-service) ;
  - les [Règles communautaires de TikTok](https://www.tiktok.com/community-guidelines) ;

  - la [Music Usage Confirmation de TikTok](https://www.tiktok.com/legal/page/global/music-usage-confirmation/en) ;
- ne pas utiliser le module pour publier des contenus illicites, trompeurs, haineux, ou du spam.
