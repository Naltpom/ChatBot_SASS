Site de démonstration

Cette page simule le site d'un client qui a installé le widget.

Pour tester :
  1. Créer un compte + un bot sur le dashboard
  2. Onglet Installation → copier la clé pk_...
  3. Remplacer data-bot-key ci-dessous (en dev, localhost est toujours autorisé)
  4. Servir cette page : python -m http.server 8080 -d demo puis ouvrir http://localhost:8080
